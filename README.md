# Master's Thesis - Luis Felipe Guevara Gomez

## Description

This repository contains the development and documentation of my master's thesis project, including:

- Thesis documentation developed in LaTeX
- MATLAB scripts
- Python scripts
- Jupyter notebooks
- Datasets and processed data
- Simulink simulations
- Figures, images, annexes, and supporting material

The repository is intended to centralize the complete research and development workflow of the project, including documentation, data analysis, modeling, experimentation, simulations, and supporting resources.

---

# Thesis Structure

## Annexes - Folder
- Anexos / Annexes → `annexes/` Folder  
  Appended tables, supplementary figures, complementary results, and additional supporting material related to the project documentation.

---

## Biblio - Folder
- Bibliography → `bibliography.tex`  
  References, citations, bibliographic sources, and citation formatting used throughout the thesis document.

---

## Chapters - Folder

- Introducción / Introduction → `introduction.tex`  
  General context, motivation, problem statement, and project justification.

- Objetivos / Objectives → `objectives.tex`  
  Research goals, project scope, constraints, and expected outcomes.

- Metodología / Methodology → `methodology.tex`  
  Methods, research workflow, development strategy, and implementation process.

- Marco Teórico / Theoretical Framework → `theoretical_framework.tex`  
  Conceptual background, theoretical foundations, mathematical concepts, and related literature.

- Entendimiento del Negocio / Business Understanding → `business_understanding.tex`  
  Problem understanding, operational context, domain analysis, and project requirements.

- Entendimiento de los Datos / Data Understanding → `data_understanding.tex`  
  Data exploration, statistical analysis, preprocessing analysis, and dataset characterization.

- Preparación de los Datos / Data Preparation → `data_preparation.tex`  
  Data cleaning, preprocessing, transformations, feature preparation, and dataset conditioning.

- Modelado / Modeling → `modeling.tex`  
  Model development, implementation, experimentation, simulations, and algorithmic approaches.

- Evaluación / Assessment → `assessment.tex`  
  Model evaluation, validation methodologies, metrics, performance analysis, and result interpretation.

- Conclusiones y Trabajos Futuros / Conclusions & Future Work → `conclusion.tex`  
  Final conclusions, project outcomes, limitations, future improvements, and possible future research directions.
